# Expense tracker

REST API for tracking personal expenses: a user records expenses by category and sees where the money went over a period. Built with Spring Boot and PostgreSQL.

## Tech stack

Java 21, Spring Boot 4.1, Spring Data JPA, PostgreSQL 16, Maven, Docker.

## Getting started

1. Start PostgreSQL in Docker:
```
docker run --name expense-db \
    -e POSTGRES_DB=expense_tracker\
    -e POSTGRES_USER=expense \
    -e POSTGRES_PASSWORD=expense \
    -p 5434:5432 \
    -d postgres: 16
```

2. Check `src/main/resources/application.properties`: the datasource URL should point to `localhost:5434/expense_tracker`.

3. Run the app (Java 21 required):

```
./mvnw spring-boot:run
```

The API is available at `http://localhost:8080`. Tables are created automatically on the first start.

## Endpoints

| Method | Path | Description |
|---|---|---|
| GET | `/categories` | List categories |
| POST | `/categories` | Create a category |
| GET | `/users` | List users |
| POST | `/users` | Create a user |
| GET | `/expenses` | List all expenses |
| POST | `/expenses` | Add an expense |
| GET | `/expenses/period?userId=&from=&to=` | A user's expenses for a period (inclusive) |
| GET | `/expenses/report?userId=&month=` | A user's total per category for a month |

### Examples

Create a user:

```json
{ "firstname": "Ali", "lastname": "Valiev", "email": "ali@example.com", "phone": "+998901234567" }
```

Add an expense:

```json
{ "amount": 15000, "date": "2026-11-01", "description": "Lunch", "userId": 1, "categoryId": 1 }
```

Report: `GET /expenses/report?userId=1&month=2026-11`.

## Key decisions

- Money is `BigDecimal` / `NUMERIC(12,2)`, never `double`.
- Validation happens in the service with clear messages; the database enforces `NOT NULL` and `UNIQUE` as a last line of defense.
- Ids are generated by the database; ids from requests are ignored.
- Errors go through one `@RestControllerAdvice`: `404` for missing resources, `400` for invalid input.
- The monthly report reuses the period query instead of duplicating the filter.
